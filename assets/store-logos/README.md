identification (the same way any price-comparison app shows a retailer's
own mark) — see `src/theme/storeLogos.ts` for how they're wired in.

Commons/Wikipedia on 2026-07-25:

Teeter files are hosted on Wikipedia under its own fair-use rationale for
illustrating each company's article, not a general reuse license — they're
used here on the same nominative-fair-use basis as the rest (identifying
which store a product/price belongs to), not as an endorsement or claim of
affiliation with either company.
